# ADRs do fiap-soat-mecanica-auth

As decisões de arquitetura deste repositório estão nas ADRs e RFCs transversais da Fase 4 (ADR-F4-01 a ADR-F4-14 e RFC-F4-01 a 03), no [`fiap-soat-mecanica-k8s`](https://github.com/fiap-postech-soat-lf/fiap-soat-mecanica-k8s/tree/main/docs/arquitetura-fase4/adr). As que mais pesam aqui: ADR-F4-06 (borda: API Gateway, Lambda Authorizer e NLB) e ADR-F4-07 (JWT RS256, com a chave pública lida do SSM).

Não há ADR específica deste repositório. Se surgir uma, ela entra nesta pasta no formato `NNNN-titulo.md` (contexto, decisão, consequências).
